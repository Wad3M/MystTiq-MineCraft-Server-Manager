# v1.3.0 — Server Health Analyzer

- Added a dedicated Health Analyzer page.
- Produces a 0–100 server health score and plain-language grade.
- Checks server folder and JAR availability.
- Opens the JAR to detect damaged archives.
- Checks server.properties and EULA acceptance.
- Validates Java compatibility for the selected Minecraft version.
- Reviews memory allocation, recent backups, and plugin-platform suitability.
- Adds completed health reports to the Notification Center.
