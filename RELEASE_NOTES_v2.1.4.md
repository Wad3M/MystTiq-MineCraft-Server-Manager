# MystMC v2.1.4 — Dark Theme Input Controls

- Added theme-aware TextBox and PasswordBox styling.
- Added dark/light-aware ListBox and ListBoxItem styling.
- Added complete theme-aware DataGrid, row, cell, and header styling.
- Added theme-aware ToolTip styling.
- Fixed editable ComboBox template support (PART_EditableTextBox) while preserving dark dropdown popup styling.
- Read-only and disabled inputs now retain readable contrast.
- All styles use DynamicResource palette brushes, so existing light themes remain light and dark themes remain dark.
