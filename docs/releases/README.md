## Earlier versions

Before moving to this repository the project was called "A Simple Minecraft Server" (versions 1.2.2 to 1.8.8) and then "MystMC" (versions 2.0.0 to 2.1.5). Those numbers were reset to 0.2.0 here. Their notes are kept in this folder as `RELEASE_NOTES_v1.*.md` and `RELEASE_NOTES_v2.*.md`. The last of them is [v2.1.5](RELEASE_NOTES_v2.1.5.md).
