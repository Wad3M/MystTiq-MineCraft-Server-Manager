# A Simple Minecraft Server v1.6.0 — UI Prototype

- Added a standalone dark green Minecraft-themed prototype window based on the supplied reference design.
- Existing application code and pages remain in the project unchanged.
- Prototype navigation buttons update the selected section title.
- Action buttons provide visual click feedback only and perform no server operations.
- Sidebar groups are expandable and collapsible.
- Server selector, scheduled-task checkboxes, scroll areas, and cards are interactive prototype controls.
- App startup currently opens `PrototypeWindow.xaml`; change `StartupUri` in `App.xaml` back to `MainWindow.xaml` to restore the functional application shell.
