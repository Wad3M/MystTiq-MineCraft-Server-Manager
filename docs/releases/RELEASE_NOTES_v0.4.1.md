# MystTiq Minecraft Server Manager v0.4.1

## MystTiq branding
- **New banner** across the top of the window: the beacon icon, **MystTiq MineCraft Server Manager**, and the version number.
- **The old "MystMC" name is gone from the app.** The window title, status bar, dialog titles and messages all say MystTiq now.
- **The startup log is now `MystTiq_startup.log`** (next to the `.exe`). An old `MystMC_startup.log` is left where it is and can be deleted.

Your servers, settings and backups are unaffected. They still live in `%APPDATA%\ASimpleMinecraftServer`.
