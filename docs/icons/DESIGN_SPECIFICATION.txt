MystCraft Icon Pack v1.0 – Master Design Specification
Global Style Guide
Every icon in this library must follow these rules:
•	Resolution: 512×512 pixels
•	Format: PNG
•	Background: Transparent
•	Perspective: ~25° isometric
•	Lighting: Top-left
•	Shadow: Soft realistic shadow beneath object
•	Padding: ~12%
•	Style: Semi-realistic Minecraft voxel art
•	Text: None
•	Borders: None
•	Scale: Consistent across all icons
•	Color Palette: Authentic Minecraft materials and colors
Whenever possible, icons should be based on real Minecraft blocks, items, mobs, entities, or mechanics, rather than generic computer symbols.
