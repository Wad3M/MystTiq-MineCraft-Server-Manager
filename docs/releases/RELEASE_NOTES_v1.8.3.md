# A Simple Minecraft Server v1.8.3

## Full-height sidebar collapse handle

- Moved the expand/collapse control from the bottom of the sidebar to a narrow full-height handle on the sidebar edge.

- Increased the three primary sidebar icons to 24 x 24 px.
- Kept the complete handle clickable in both expanded and collapsed states.
- Added theme-aware handle background, border, hover, and pressed states.
