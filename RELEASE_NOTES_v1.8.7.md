# A Simple Minecraft Server v1.8.7

## MystUI Scrollbar Polish

- Replaced the default Windows scrollbar with a slim 9 px MystUI scrollbar.
- Scrollbar track, thumb, hover, and dragging states now use active-theme resources.
- Added rounded scrollbar thumbs and tracks.
- Reduced idle visual weight with a partially transparent thumb and track.
- Increased visibility on hover and while dragging.
- Applied the style globally to ScrollViewer, ListBox, ComboBox, DataGrid, TextBox, console, and other scrolling controls.
- Added matching horizontal scrollbar styling.
- Updated application version to 1.8.7.
