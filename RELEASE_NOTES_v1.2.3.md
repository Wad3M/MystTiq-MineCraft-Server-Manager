# A Simple Minecraft Server v1.2.3

## Change Minecraft Version
- Added a safe version-change workflow in Update Center.
- Loads recent official Minecraft release versions.
- Resolves matching Paper, Purpur, or Vanilla server downloads.
- Requires the server to be stopped.
- Creates a complete safety backup and preserves the previous JAR.
- Updates the selected profile and installed-build marker only after successful installation.
- Warns that world downgrades can be destructive and recommends restoring the safety backup if needed.
