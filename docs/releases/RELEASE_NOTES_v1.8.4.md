# A Simple Minecraft Server v1.8.4

## Multi-size icons and themes
- Added pre-rendered 16, 20, 24, 27, 32, 36, 48, and 64 px icon variants for crisper presentation at each UI scale.
- Increased primary sidebar icons from 24 px to 36 px.
- Increased section navigation icons from 18 px to 27 px.
- Increased expanded and collapsed sidebar widths to preserve comfortable spacing around the larger icons.
- Added Metallic Silver theme.
- Added Nether Crimson theme.
- Updated runtime theme switching and persistence for all five themes.
